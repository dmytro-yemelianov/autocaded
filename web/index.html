About AutoCADED

AutoCADED — AutoCADED for Dmytro Yemelianov (Emelyanov). A native Rust reimplementation of AutoCAD 1.4 (1983, MS-DOS) for the original 2D drafting workflow.

What this is

  • Complete 1983 DWG/DXF codec (AC1.2 + AC1.40)
  • All 54 software commands recognized; 44 differentially verified against original ACAD.EXE
  • Native window (winit + softbuffer), WebAssembly, Unix socket API, MCP stdio adapter
  • SHP stroke fonts, render budget (1M work units/frame), bounded hit-testing
  • Hand-written Rust — decompiler guides understanding; all shipped code is original

What this is not

  • Not an Autodesk product — AutoCAD is a trademark of Autodesk, Inc.
  • Not a modern CAD — this is 1983 2D only (no 3D, no Xrefs, no LISP)
  • Hardware commands excluded: TABLET, PLOT, QPLOT

Verification

The original ACAD.EXE under QEMU is the oracle. Every claim names its evidence: original exports, CGA frame comparisons, retained HLP pages, or Rust tests. No behaviour is asserted without differential proof.
